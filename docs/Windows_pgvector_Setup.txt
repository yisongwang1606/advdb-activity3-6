Reproduction on a suitable Windows computer
-------------------------------------------
Install PostgreSQL 18 and Visual Studio 2022 Build Tools with the C++ x64 tools
and a Windows SDK from their official vendors. Then open an x64 Native Tools
Command Prompt as administrator and run the official source-build steps below.
Use a writable checkout directory and adjust PGROOT if PostgreSQL is elsewhere.

  set "PGROOT=C:\Program Files\PostgreSQL\18"
  git clone --branch v0.8.7 --depth 1 https://github.com/pgvector/pgvector.git
  cd pgvector
  nmake /F Makefile.win
  nmake /F Makefile.win install

The original machine used the same compiled file set with a PowerShell copy
installer to permit explicit per-file hash verification; it did not use a
third-party precompiled DLL.

In pgAdmin connected to the target activity database:

  SELECT * FROM pg_available_extensions WHERE name = 'vector';
  CREATE EXTENSION IF NOT EXISTS vector;
  SELECT extversion FROM pg_extension WHERE extname = 'vector';
